# BetterInventory 3.8.0 — file-by-file audit (2026-11-07)

Read-only audit of all 93 runtime Lua modules (~62k lines), split into nine
subsystems. Items already fixed or deferred in
`v3.8.0-darktide-1.13.4-audit.md` were excluded. Nothing was changed in code.

Legend: **[V]** = mechanism re-checked against source by the coordinating
session; the rest were verified by the subsystem auditor only. Severity is
H/M/L. Line numbers are as of commit `60799b2`.
