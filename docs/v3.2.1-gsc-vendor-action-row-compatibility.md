# v3.2.1 God Stat Checker vendor action-row compatibility

## Outcome

Armoury Exchange Requisition and GlobalStore Multi-Operative Supply both use Darktide's `CreditsVendorView`. Their Acquire button belongs to a fixed bottom-aligned scenegraph node, while the selected item's right-hand `ViewElementWeaponStats` panel chooses its final height from the presented content. God Stat Checker's additional verdict and explanation rows can therefore extend the panel through the fixed Acquire slot.

Better Inventory now reconciles the shared action row against the final live `grid_background` rectangle. If the God Stat Checker panel reaches the native button slot, Acquire is placed eight virtual pixels below the panel. A shorter panel leaves Darktide's native Y coordinate unchanged. The rule also composes with Quick Level Mastery's existing two-button horizontal centering and God Stat Checker's own reduced-height behavior when that Sacrifice row is present.

## Ownership and performance contract

- The vertical rule is active only while Better Inventory's reconciled God Stat Checker lifecycle state is active.
- GSC availability is cached at install, setting, enable, and disable boundaries; the vendor update does not resolve another mod or read DMF settings every frame.
- Stable frames compare existing scalar identities and dimensions only. Full scenegraph verification retains the existing once-per-15-update cadence, while an actual panel-height or button-coordinate change wakes it immediately.
- Better Inventory records the pre-adjustment Y coordinate, performs no write when the target is already correct, and restores only a coordinate it still owns when GSC is disabled, removed, or the view is released.
- An external rewrite becomes the new baseline instead of being overwritten later by a stale restoration value.
- The compatibility path creates no widget, item registry, backend request, or frame-lived allocation.

## Regression coverage

The feature-domain harness now verifies a tall 920-pixel GSC panel, an immediate live height change, GSC disable restoration, a short-panel native-placement case, and release-time restoration. The GSC integration harness also verifies cached active, display-disabled, mod-disabled, and absent states.
